# Brand & Design Brief — "4 ปีมหาลัย"

> สถานะ: **v1 อนุมัติแล้ว** (2026-11-11) · ได้มาจากการ grill ผู้ใช้ 2 รอบ

> ทุก station / subagent ต้องทำตามไฟล์นี้ ถ้าขัดกับ CLAUDE.md ให้ CLAUDE.md ชนะ

## 1. Brand archetype: **Jester + Sage**

| | Jester (ตอนเล่น) | Sage (ตอน reveal) |
|---|---|---|
| บทบาท | เพื่อนที่ป่วน แซว ทำให้ขำตัวเอง | เพื่อนเนิร์ดที่อธิบายว่าทำไมสมองทำแบบนั้น |
| อยู่ที่ไหน | intro, Play, memory line, mascot, share card | หน้า reveal: กลไก → งานวิจัย → วิธีรับมือ |
| ห้าม | ห้ามเฉลย bias, ห้ามแซวตัวคน | ห้ามเทศนา, ห้ามตัดสิน, ห้ามอ้างตัวเลขที่ไม่ verified |

**ความรู้สึกเป้าหมายตอนจบ:** ผู้เล่น *ขำตัวเอง แล้วอยากแชร์* ("โดนว่ะ ส่งให้เพื่อนเล่นบ้าง")

**ไม่ใช่:** เว็บมหาลัย/ราชการ · แบบทดสอบบุคลิกภาพ (MBTI/ดูดวง) · Startup/SaaS landing

## 2. Voice: เพื่อนสนิทที่ชอบแซว

- พูดแบบเพื่อนคุยกัน ใช้ "เรา/แก/เธอ" ได้ ไม่ใช้ "ท่าน" ไม่ใช้ภาษาราชการ
- **แซวพฤติกรรม ไม่แซวคน:** ขำที่ "สมองมนุษย์" ไม่ใช่ที่ผู้เล่น และปิดด้วยความรู้สึกว่า "ทุกคนก็เป็น"
- เรื่องเงิน/หนี้ และผลการเรียน: แซวให้เบาลงอีกขั้น ห้ามทำให้รู้สึกผิด
- ประโยคสั้น ทีละเรื่อง ปุ่มเป็นคำกริยาที่บอกว่าจะเกิดอะไร ("เริ่มปีหนึ่ง", "ไปช่วงต่อไป")
- ศัพท์ BE ใช้ภาษาอังกฤษ (present bias, sunk cost) **เฉพาะหน้า reveal**

| ✅ แบบนี้ | ❌ ไม่ใช่แบบนี้ |
|---|---|
| "บอกว่าแป๊บเดียว... 11 นาทีนะเพื่อน" | "คุณมี present bias สูง" (เฉลยระหว่างเล่น) |
| "สมองคนเราชอบของตอนนี้มากกว่าของทีหลัง ไม่ใช่แค่แก" | "คุณควบคุมตัวเองไม่ได้" (แซวตัวคน) |
| "งวดละนิดเดียว รวม ๆ แล้วก็... ไม่นิดนะ" | "คุณกำลังจะเป็นหนี้" (ทำให้รู้สึกผิด) |

## 3. Mascot: "ต่อม" สมองจอมป่วน

- สมองก้อนกลม เส้นหมึก navy เติมสีไฮไลต์ชมพู ทำแบบเดียวกับภาพตึก (เส้นหมึก + สีเหลื่อม)
- **ตอนเล่น:** โผล่มุมจอเป็นจังหวะ (ไม่เกิน 1 ครั้งต่อ station) พูดแซวเป็นกลาง ไม่เฉลย
- **ตอน reveal:** สารภาพว่า "โทษที ผมทำเอง" แล้วอธิบายกลไก (เป็นสะพานจาก Jester ไป Sage)
- ท่าทาง 4 แบบ (`src/components/Mascot.tsx`): `idle` ปกติ / `sly` ยิ้มเจ้าเล่ห์ / `confess` ยกมือสารภาพ / `celebrate` ฉลองรับปริญญา
- มี `<Bubble>` ไว้ใช้เป็นคำพูด ตอนนี้ใช้ใน Memory (sly), Graduation (celebrate) และ Reveal (confess)

## 4. Visual CI: "สมุดจดไฮไลต์" (ink + highlighter)

ทำไมเลือกแบบนี้: ใช้งานได้กับเว็บเราเลย ลงทุนน้อย และอยู่ในโลกของนักศึกษาจริง (สมุดเลคเชอร์ + ปากกาไฮไลต์)
ฝั่ง Sage คือสมุดจดที่เป็นระเบียบ ฝั่ง Jester คือดูเดิล สติ๊กเกอร์ และเทปที่แปะไว้

### สี (tokens อยู่ใน `src/index.css`)

| Token | Hex | ใช้ทำอะไร |
|---|---|---|
| `paper` | `#F6F7FB` | พื้นหลัง (ขาวอมฟ้า สะอาด) |
| `card` | `#FFFFFF` | การ์ด, polaroid |
| `ink` | `#1E2240` | ตัวอักษร เส้น ปุ่มหลัก (navy เหมือนกระโปรง/กางเกงนักศึกษา) |
| `muted` | `#5C6178` | ข้อความรอง |
| `line` | `#E3E5EE` | เส้นแบ่ง, track |
| `y1` ปี 1 | `#FFE94D` เหลือง | ไฮไลต์ |
| `y2` ปี 2 | `#FF9FCD` ชมพู | ไฮไลต์ + สีของต่อม |
| `y3` ปี 3 | `#7DE8B4` มิ้นต์ | ไฮไลต์ |
| `y4` ปี 4 | `#8FD0FF` ฟ้า | ไฮไลต์ |
| `grad` | `#FFB45C` ส้ม | รับปริญญา / ใบเกรด |

กฎ: สี `mark` (ไฮไลต์) **ห้ามใช้เป็นสีตัวอักษร** ให้ใช้เป็นพื้นหลังที่มีตัวอักษร ink วางอยู่ ถ้าต้องการตัวอักษรเป็นสีประจำปี ให้ใช้ `*-deep` (contrast ≥ 4.5:1)
ใน code: `YEAR_ACCENT[year].mark | .deep | .soft`, `GRAD_ACCENT`

### Typography (ผู้ใช้ OK แล้ว)
- Display: **Prompt** 600–700 · Body: **Noto Sans Thai** 400–600
- Body ≥ 16px, line-height 1.6

### ภาษาภาพ
- **เส้นหมึก navy 2–2.5px + สีไฮไลต์พิมพ์เหลื่อม** (offset ไปทางขวาล่าง 3–5px): ใช้กับภาพประกอบทุกชิ้น
- **ปุ่ม/ไทล์สติ๊กเกอร์:** ขอบ ink 2px, เงาแข็ง `0 4px 0 ink` และกดแล้วยุบลง
- **Icon:** ใช้ `lucide-react` stroke 2 สี ink ห้ามใช้ emoji เป็น icon (แต่ละ OS แสดงต่างกัน)
- **Signature motion มีอย่างเดียว:** ปากกาไฮไลต์ปาดใต้หัวข้อหลัก (`<Highlight>`) ใช้เฉพาะหัวข้อใหญ่ไม่กี่จุด
- การ์ด: ขาว ขอบบาง ไม่ใช้เงาเบลอซ้ำ ๆ ไม่ใช้ gradient
- หลีกเลี่ยง: ครีม + terracotta, eyebrow ตัวพิมพ์ใหญ่, การต่อข้อความด้วย "·", ลูกศร "→" ท้ายปุ่ม

### Motion
- เปลี่ยนฉากด้วย fade + เลื่อน 16px ใช้เวลา 0.35s · motion ที่ตอบสนองการกดใช้ 100–150ms
- เคารพ `prefers-reduced-motion` เสมอ (`useReducedMotion`)

## 5. Share card: ใบเกรดล้อเลียน

หน้าตาเป็น transcript มหาลัย แต่วิชาเป็นพฤติกรรม เช่น

```
┌──────────────────────────────────────┐
│ BEHAVIORAL TRANSCRIPT   ปีการศึกษา 4 ปี │
│──────────────────────────────────────│
│ SCRL101 ไถแป๊บเดียว            B+    │ ← ไฮไลต์เหลือง
│ BUY102  ผ่อนสบาย ๆ             C     │
│ SUNK201 เสียดายของ             A     │
│ TEAM301 งานกลุ่ม               B     │
│ THES401 เดี๋ยวค่อยทำ            D+    │
│──────────────────────────────────────│
│ หมายเหตุอาจารย์: "..." (แซวพฤติกรรม)  │
│ ลายเซ็น: ต่อม 🧠  · 4unilife.xxx       │
└──────────────────────────────────────┘
```
- เกรดคำนวณจากระยะห่างจาก rational (A = ใกล้ rational) และต้องมีหมายเหตุว่า "เกณฑ์เป็นของเราเอง ไม่ใช่ norm"
- ชื่อวิชาเป็นกลาง (หน้า share card อยู่หลัง reveal แล้ว จะใส่ชื่อ bias ตัวเล็กก็ได้)
- ห้ามดูเหมือนผลแบบทดสอบบุคลิก: ไม่มี "คุณคือคนประเภท..."
